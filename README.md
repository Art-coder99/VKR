# ARUM-PRIOR — электронный журнал

Учебное FastAPI-приложение для сотрудников. Запись работ, организации, справочник услуг, фиксирование стоимости на момент записи, доступ по ролям, отчёты XLSX/PDF, история удаления/правок.

## Быстрый запуск на Windows

1. Установите Python 3.11+ с python.org (галочка Add Python to PATH).
2. Распакуйте ZIP и запустите `run_windows.bat`. При первом запуске нужен интернет, чтобы установить библиотеки.
3. Откройте http://127.0.0.1:8000.
4. Учебные учётные записи: `director` / `Admin123!`, `employee1` / `Employee123!` (также `employee2`, `employee3`, `employee4`). **Сразу смените все пароли в разделе «Сотрудники»!**

При обычном запуске используется локальная база `arum.db` (SQLite) без установки СУБД. Для реальной эксплуатации можно использовать PostgreSQL, указав `DATABASE_URL` в переменных окружения перед запуском. `.env.example` показывает формат подключения; файл .env автоматически **не** подгружается.

## Запуск вручную

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
# source .venv/bin/activate
pip install -r requirements.txt
python -m uvicorn app.main:app --reload
```

## Эксплуатация и ограничения

- Для реальной эксплуатации: уникальный `SECRET_KEY`, сменить все пароли, настроить HTTPS и резервные копии.
- Стандартные учебные цены и организация — демонстрационные.
- Все пользователи могут просматривать журнал, но сотрудники изменяют и удаляют только собственные записи. Отчёты и администрирование доступны директору.
- При удалении запись помечается удалённой и исключается из отчётов. История содержит автора, время и действие; это не полный снимок всех изменённых полей.
- Цены старых записей сохраняются при изменении справочника. При замене услуги в записи применяется актуальная цена новой услуги.
- Отчёт PDF с кириллицей требует локальный шрифт DejaVuSans или Arial.
- Для упрощения проекта миграции схемы БД не предусмотрены. Изменения структуры после начала эксплуатации потребуют отдельной миграции.
